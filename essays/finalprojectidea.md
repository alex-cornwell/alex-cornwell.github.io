# Event Management System for Campus Clubs

### Overview
_The Problem_

University clubs and organizations that have trouble managing and promoting their events can result in reduced student engagement and participation.

_The Solution_

An Event Management System for Campus Clubs can serve as a centralized platform for clubs to organize, promote, and manage events. The platform will enable clubs to manage member lists, schedule events, and engage with attendees efficiently, fostering a more connected campus community.

### Approach
The Event Management System aims to create an easy to use platform to streamline event management for university clubs. By serving as a centralized hub, the platform will simplify the hassle of organizing events and promoting them to students, increasing overall engagement.

### Mockup Page Ideas
- Home page
- Club Dashboard - For clubs to manage events and member lists
- Event Listings Page - To display and promote events across all clubs
- Event Detail Page - To provide specifics on event times, locations, and RSVP  options
- Sign-up/Login Page - User authentication for students and club administrators
- Admin Home Page - Special dashboard for campus club coordinators

### Use Case Ideas
The following use cases demonstrate scenarios for different users of the system:
- A new user goes to the landing page, logs in, views the home page, and sets up a profile.
- A club admin logs in, creates an event, and manages RSVP’s.
- Students sign up for events, view details, and get reminders before the event.
- Admins can edit events, manage club information, and interact with members.

### Beyond the Basics
After implementing basic functionality, the following advanced features could enhance the platform:
- Map Integration - Integrate with a map API to display event locations, making it easier for students to find venues.
- Customizable Event Notifications - Allow students to set preferences for receiving event reminders (email, text).
- Point System - Implement a point system where students earn points for attending events, redeemable for rewards or recognition.
- Social Media Integration - Allow clubs to share events directly to social media platforms to reach a broader audience.
